## 실습에 대한 설명

아두이노의 5V 핀과 GND 핀을 브레드보드에 연결하여 전원 공급 경로를 구성했습니다.
setup() 함수에서는 pinMode()를 사용하여 디지털 7번 핀을 출력(OUTPUT) 모드로 설정하였고, loop() 함수에서는 digitalWrite()로 HIGH(5V)와 LOW(0V)를 번갈아 출력하여 LED가 1초 간격으로 켜지고 꺼지도록 했습니다.

- pinMode(7, OUTPUT) : 7번 핀을 출력으로 설정
- digitalWrite(7, HIGH) : 7번 핀에 HIGH 전압 출력 -> LED 켜짐
- digitalWrite(7, LOW) : 7번 핀에 LOW 전압 출력 -> LED 꺼짐
- delay(1000) : 1000ms 대기


## 기본 개념 정리

### 임베디드 시스템

**Embedded Systems는 크게 High-level, Low-level로 나눌 수 있습니다.**

**High-level (SBC,ROS2)** : 실제 추론을 담당, 센서 데이터 처리 및 주변 환경 인식, 카메라, LIDAR 등 대용량 센서 데이터 처리, Localization/Mapping/SLAM 수행, 높은 연산 성능과 메모리 요구, 처리 성능 중시, SBC는 리눅스 기반으로 다양한 소프트웨어 및 고성능 연산 환경 수행

perception : 카메라, LiDAR 등의 센서 데이터를 분석하여 주변 환경과 객체를 인식
planning : 인식된 환경과 목표를 바탕으로 로봇의 행동 및 이동 경로를 계획
navigation : 위치 추정, 지도 및 경로 계획을 활용하여 로봇을 목표 지점까지 이동


**Low-level (MCU,RTOS)** : 실제 하드웨어를 빠르고 일정한 주기로 제어, Encoder 데이터 처리, 각종 센서 데이터 수집 및 전처리, 짧고 일정한 주기의 제어 수행, 버퍼링 및 딜레이 방지 필수, 실시간성 중시, MCU는 단순하게 전압만 느끼는 장치

Motor : 전기 신호를 받아 로봇을 실제로 움직이는 구동 장치
Encoder : 모터의 회전량, 위치, 속도 등을 측정하여 시스템에 피드백 제공
Control : 목표값과 실제 측정값의 오차를 계산하여 모터 출력 등을 실시간으로 조절


**High-level, Low-level 분리이유**

- High-level은 많은 연산량을, Low-level은 빠르고 일정한 제어 주기가 필요합니다.
- 로봇 주행은 단순한 모터 제어만으로 이뤄지지 않기 때문입니다.
- Low-level은 완벽한 제어 주기를 가지고, High-level은 제어 주기가 변할 수 있습니다.


**임베디드 시스템**

- 특정 기능을 수행도록 설계된 시스템으로 MCU 기반으로 동작합니다.
- 낮은 연산량과 제한된 컴퓨팅 자원을 가지고 있습니다.
- 실시간 처리 및 제어에 적합합니다.


### ESP32

**ESP32** : 센서에서 정보를 받아 처리하고 LED나 모터 같은 전자장치를 제어하는 MCU 입니다. 핀들은 전압을 읽으며, input pin에 들어오는 빛 등의 정보를 받아 연산을 처리하여 output pin에 연결된 장치를 제어합니다.


**VCC와 GND** : 전원에서 VCC와 GND 사이에 전압을 공급하면 회로가 연결되었을 때 전류가 흐릅니다.
옴의 법칙(V=IR)을 따라, 같은 전압을 가했을 때 저항이 클수록 전류는 작아집니다. 


**Common Ground** : 두 개 이상의 전자장치를 연결할 때 서로 같은 0V 기준점을 사용하도록 GND를 연결하는 것입니다. 


**GPIO** : GPIO는 MCU에서 입력(Input)과 출력(Output)으로 사용할 수 있는 범용 핀입니다.
디지털 GPIO는 전압을 연속적인 값으로 읽기보다, 일정 기준에 따라 LOW 또는 HIGH의 두 상태로 판단합니다. ESP32에서는 로직 볼트로 보통 LOW는 0V, HIGH는 3.3V를 사용합니다. 또한 아날로그 센서의 전압을 읽으려면 ADC를 사용합니다.


**ADC와 DAC**
- ADC(Analog-to-Digital Converter)는 아날로그 전압을 디지털 숫자로 바꾸는 장치입니다. ESP32의 12비트 ADC는 아날로그 측정값을 일반적으로 0~4095의 숫자로 나타냅니다
- DAC(Digital-to-Analog Converter)는 디지털 전압을 아날로그로 바꾸는 장치입니다. ESP32의 8비트 DAC는 있어서 0~255의 아날로그 측정값을 내보냅니다.
